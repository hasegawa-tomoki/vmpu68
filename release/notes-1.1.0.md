VMPU68 1.1.0 — 基板 V2.0.1 対応と不具合修正(Raspberry Pi 4 カーネル 1.1.0 / FPGA 1.0.0)

## 主な変更
- 基板 V2.0.1 に対応しました。同じファームウェアが V1.0 と V2.0.1 の両方で動きます(起動時に自動判別)。
- V2.0.1 では Raspberry Pi と FPGA の間の転送に SMI(SoC の並列バス機能)を使います(既定 ON。Web UI の「SMI 転送」、`VMPU68 -t1|-t0`、vmpu68.cfg の `smi=` で切替)。バス操作が 1〜2 割速くなり、si.x の machine performance は 177% → 198% です。
- ADPCM の再生中に音が乱れる問題を直しました(DMA 転送が Raspberry Pi 側の書込みキューに待たされていたため。ADPCM の DMA が動いている間だけキューを浅くします)。V1.0 にも有効です。
- 68000 のバスエラー例外のスタックフレームが 68010 形式になっていたのを 68000 形式(14 バイト)に直しました。バスエラーを自前で処理するソフト(ハードウェア探査など)が正しく復帰します。V1.0 にも有効です。
- VMPU68 の情報ポートを `$ECFF00` から `$ECD000` に移しました。旧番地は FineScanner-X68(スロット F)や BANK RAM ボードと重なり、si.x にも誤表示されていました。**VMPU68.X も同梱の新しいものに入れ替えてください**(1.0.0 の VMPU68.X はこの版では動きません)。
- JIT を既定 ON にしました。
- Web UI: 「基板」の版数表示、「SMI 転送」(V2.0.1 のみ表示)。
- VMPU68.X: `-t1|-t0`(SMI)を追加。表示 2 行目に SMI の状態を出します。
- X68000 の電源が OFF のときの扱い(V2.0.1 では FPGA が Raspberry Pi から給電されるため)とアクセス監視の解除の不具合を直しました。

## 添付ファイル
- `vmpu68-sd-1.1.0.img.xz` … SD カードイメージ。Raspberry Pi Imager で書き込んでください(初回はこれを使います)
- `vmpu68-sd-1.1.0.zip` … 同じ SD カードイメージの zip 版
- `vmpu68-1.1.0.vpk` … 更新パッケージ。Web UI の「ファームウェア」から適用します(カーネル + FPGA)

Human68k 側のコマンド `VMPU68.X` と 2HD イメージ `VMPU68.XDF` はリポジトリの `release/Human68k/` にあります。
設定ファイルの見本(`vmpu68.cfg.sample`、`wpa_supplicant.conf`)は `release/config/` にあります。

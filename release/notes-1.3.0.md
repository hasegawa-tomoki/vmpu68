VMPU68 1.3.0 — 仮想SCSI対応 (Raspberry Pi 4 カーネル 1.3.0 / FPGA 1.2.0)

## 機能追加

- 仮想SCSIを追加しました。
  - Raspberry PiのSDカードに置いたディスクイメージ(hds)を、X68000からはSCSIディスク(ID 0〜6)として使えます。
  - IOCSのSCSI呼び出しをPi側で処理し、データをシャドウRAMへ直接置くので、内蔵SCSI経由より速く転送できます(Human68kからの読み出しで約15 MB/s)。
  - 内蔵SCSIの機器(vhd68など)と共存できます。イメージをマウントしたIDだけをPiが受け持ち、それ以外は内蔵SCSIへそのまま渡します。
  - ID 0にマウントするとIPLはそのイメージから起動します(起動ディスクにはIPLと常駐ドライバが必要です。FORMAT.Xで作ったイメージはそのまま使えます)。
  - Web UIに「CPU」「仮想SCSI」のタブを追加しました。仮想SCSIタブで、IDごとのマウント/イジェクト、SDカードの残り領域のイメージ用ボリュームへの初期化、イメージのアップロード・新規作成・名前変更・削除、イメージ内のファイルの一覧・取り出し・追加・削除ができます。
  - vhd68、vfd68とのLAN連携に対応しました。近くの機器にあるイメージを取り込んだり、こちらのイメージを転送してマウントできます。
  - vmpu68.cfgに`vscsi<ID>=<path>[,ro]`を追加しました(起動時にマウント。Web UIの操作で自動的に保存されます)。
- VMPU68.Xに`-d`を追加しました。
  - Human68kのドライブ一覧(ドライブ文字、ドライバ名、SCSI ID、vhd68、vfd68、仮想SCSIのイメージ名)を表示します。
- VMPU68.Xの表示を整理しました。

## 注意

- Human68k稼働中にマウント中のIDのイメージを差し替えたとき、SHARP標準の常駐ドライバ(SCHDISK)が受け持つドライブでは直後の書込みが失敗することがあります。Human68kのバッファの扱いによるもので、vhd68でも同じです。差し替えを使うIDはSxSIのSCSIHD.SYSかsusie.xに受け持たせるか、差し替えのあとにリセットしてください。
